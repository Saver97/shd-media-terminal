# SHD 影音终端

一款面向 Windows 的轻量桌面工具：查看每周新番、搜索动漫花园资源、追踪订阅更新，并把选中的磁力链接交给本机迅雷。

界面采用简约深色与橙色点缀，基于 Python、PySide6 和 Qt WebEngine。当前提供源码运行方式，尚无独立安装包。

## 功能

- **新番日历**：按星期浏览 Bangumi 放送表，查看封面和名称，一键搜索或追番。
- **资源搜索**：支持分页、清晰度及字幕筛选，展示发布组、大小与做种数。
- **我的追番**：按关键词、发布组、清晰度和字幕订阅；支持单项折叠、全部展开/收起及标题行封面。
- **多选交接**：追番资源可逐条勾选或全选，批量交给迅雷；相同磁链去重，失败条目保留勾选。
- **迅雷下载**：自动检测安装位置，也可手动选择 Thunder.exe；支持单条资源交接和历史记录。
- **网络设置**：支持系统代理、手动 HTTP/SOCKS 代理及直连，设置通过弹窗修改。
- **中文名称**：优先展示上游中文名，缺失时尝试带标记的暂译或机翻。

应用不包含 BT 下载引擎，不下载、缓存或播放视频。迅雷接收磁链后，由用户在迅雷中确认文件及保存位置；“已发送”仅表示已发出启动请求，不代表下载成功。

## 安装与启动

需要 Windows、Python 3.10 或更新版本，以及已安装的迅雷桌面客户端。当前主要在 Windows / Python 3.10 环境验证。

在 PowerShell 中执行：

```powershell
git clone https://github.com/Saver97/shd-media-terminal.git
cd shd-media-terminal
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

依赖安装后，也可以双击 `启动影音终端.vbs` 静默启动，或使用 `启动影音终端.cmd` 查看启动错误。

首次运行会自动创建 `data/`。如果没有识别到迅雷，进入左下角设置，选择本机 `Thunder.exe`。

## 使用方式

1. 在新番日历中选择星期，点击作品的“查看资源”；也可以在“发现资源”直接搜索。
2. 选择资源后点击“迅雷下载”，在迅雷窗口中确认下载。
3. 想持续关注作品时，添加追番并设置版本条件。程序运行期间每 30 分钟检查一次，也可以手动检查。
4. 在追番列表勾选资源，点击“迅雷下载所选”。每个番目目前最多展示前 8 条资源，全选范围为这些已列出的资源，包含折叠番目。

关闭本工具不会停止迅雷下载，也不会在后台继续检查追番。

## 代理和本地数据

资源站代理用于搜索、更新检查、日历、封面及译名请求。手动地址示例为 `http://127.0.0.1:7897` 或 `socks5h://127.0.0.1:7897`，请替换为自己的端口。

**迅雷的网络由迅雷自身管理。** 本工具不会把资源站代理参数传给迅雷，也无法替代迅雷的网络设置。

| 位置 | 内容 |
| --- | --- |
| `data/library.json` | 设置、订阅及交接记录 |
| `data/calendar.json` | 日历缓存 |
| `data/calendar-covers/` | 封面缓存 |
| 浏览器本地存储 | 追番折叠状态 |

日历通常缓存 6 小时，手动刷新可以更新；封面缓存 7 天，译名缓存 30 天。网络不可用时日历可能使用旧缓存。公开标题可能发送至 MyMemory 进行翻译；机翻条目仍优先使用原名搜索。

`data/` 不纳入版本控制。分享程序时不要附带自己的配置和历史数据。

## 数据来源与限制

- 放送安排：[Bangumi](https://bgm.tv/)，通过其公开日历接口获取。
- 搜索结果：[动漫花园](https://share.dmhy.org/)。页面结构或访问限制变化可能影响搜索。
- 自动译名：[MyMemory](https://mymemory.translated.net/)。译名可能不准确，界面会标记。

日历并非所有影视作品的完整目录，放送日期也不等于字幕资源发布日期。追番封面依赖日历中可匹配的作品，未匹配时显示占位。应用需要联网访问上述服务，不提供这些服务的可用性保证。

本项目不托管影视文件。请仅下载和使用你有权获取的内容；第三方服务、封面及作品名称归各自权利人所有。本项目不隶属于 Ubisoft、Bangumi、动漫花园或迅雷。

## 开发

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

| 文件 | 用途 |
| --- | --- |
| `app.py` | Qt 桌面窗口、标题栏与 WebChannel 桥接 |
| `core.py` | 搜索、订阅、存储和迅雷交接 |
| `calendar_source.py` | 放送表及封面缓存 |
| `title_names.py` | 中文名及翻译缓存 |
| `ui/` | HTML、CSS、JavaScript 和本地图标 |
| `tests/` | 核心逻辑测试 |
